# The SE Trainee MCQ Cracker

**A senior engineer's 5-day crash guide for the Bangladeshi trainee hiring exam.**

---

## How to use this handbook

This is **not a textbook**. It's a weapon tuned for one thing: **maximizing your MCQ score** on a trainee software engineer exam. Everything is filtered through the **Pareto Principle** — the ~20% of concepts that show up in ~80% of questions. Low-frequency theory is deliberately cut.

Every topic follows the same rhythm:
- **Why it matters** (with notes on which BD companies test it hardest)
- **Essential concepts** — dense, no padding
- **Frequently confused concepts** — the traps interviewers love
- **Common mistakes & memory tricks**
- **Cheat sheet + top facts to memorize**
- **MCQs with a full answer key** (attempt first, then check)

> 💡 **The one rule:** For every MCQ, **attempt it before reading the answer.** Passive reading feels productive but doesn't build recall. Cover the answer key, commit to a choice, *then* check. That single habit is worth 10–15 marks.

## What Bangladeshi trainee exams actually look like

Based on the pattern at the target companies:

- **Format:** 40–70 MCQs, 60–90 minutes. Often an online platform (HackerRank, TestGorilla, or in-house).
- **Some companies add** 1–2 short coding problems after the MCQ round (arrays, strings, basic logic). This handbook keeps you MCQ-ready; brush up basic coding separately.
- **Heaviest topics:** OOP, SQL, output-prediction (C/C++/Java), data structures, complexity (Big-O), OS basics, aptitude/logic.
- **Company leanings:**
  - **Therap, Brain Station 23, Enosis, BJIT** → Java-heavy OOP + DS/Algo + SQL.
  - **WellDev, Selise** → .NET/C#, JavaScript/TypeScript, plus general CS + logic.
  - **Cefalo, TigerIT, DataSoft** → strong CS fundamentals + aptitude.
- **Negative marking:** Some do, some don't. Assume it *might* — so **eliminate options** rather than wild-guess when unsure (technique covered in the final section).
